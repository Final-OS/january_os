# v0.1/v0.2 技术债务完整清单

本文详细列出 v0.1 和 v0.2 版本中所有未完成、不完备的功能，并明确分配到后续版本。

---

## 状态说明

| 标记 | 含义 |
|------|------|
| 🔴 | **阻塞**：核心功能缺失，阻塞用户程序运行 |
| 🟡 | **不完备**：功能存在但不完整，需要完善 |
| 🟢 | **完备**：功能完整，无需额外工作 |

### 最小集偿还原则（新增）

- `v0.3` 允许以“主链路最小集可运行”为阶段目标。
- 所有最小集能力都必须在后续版本补齐到完整实现，不允许长期冻结在“最小可用”状态。
- 本文新增的“v0.3 最小集技术债”条目，均属于必须偿还债务。

## 版本归属汇总

### v0.3 (2026-Q3) - 文件系统与块设备

**目标**：打通"磁盘 → 文件系统 → 用户程序"链路

#### v0.3.0 主链路必须完成

| 类别 | 项目 | 优先级 |
|------|------|--------|
| **块设备** | virtio-blk + 分区（MBR/GPT）主链路 | 🔴 阻塞 |
| **VFS** | FileSystem/Inode/File trait, mount, 路径解析 | 🔴 阻塞 |
| **文件系统** | FAT32 只读 + ext4 只读（必选） | 🔴 阻塞 |
| **Syscall** | lseek/getdents64/dup/dup2/fcntl/chdir/getcwd（最小子集） | 🔴 阻塞 |
| **ELF** | argv/envp/auxv 栈帧 + VFS 加载 | 🔴 阻塞 |

#### v0.3.x 继续偿还（最小集补全）

| 子版本 | 债务项 |

## 债务燃尽图

```
v0.2 基线债务
    │
    ├─→ v0.3.0 交付主链路最小集（含 ext4 只读必选）
    │
    ├─→ v0.3.1 / v0.3.2 偿还最小集遗留债务（procfs、扩展 syscall、动态链接、sysfs、ext4 增强）
    │
    ├─→ v0.4-v0.6 持续偿还文件系统/用户空间/网络相关阻塞项
    │
    ├─→ v0.7-v0.8 新增多架构债务并并行收敛
    │
    └─→ v0.9-v1.0 完成安全与生产就绪收口
```

---

## 验收原则

1. **每个版本必须减少 🔴 阻塞项数量**
2. **v0.3-v0.6 专注偿还阻塞债务**
3. **v0.7-v0.8 专注架构移植**
4. **v0.9-v1.0 专注安全与生产就绪**
5. **v1.0 前所有 🔴 阻塞项必须清零**
6. **所有“最小集”能力必须在后续版本偿还为完整实现**
