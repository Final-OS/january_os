# layout - 内存布局常量

定义内核的虚拟内存布局和关键地址常量。

## 地址常量

```rust
// kernel/src/mm/layout.rs

// ============================================================================
// 直接映射区
// ============================================================================

pub const DIRECT_MAP_OFFSET: u64 = 0xFFFF880000000000;
pub const DIRECT_MAP_END: u64 = 0xFFFFC80000000000;

// ============================================================================
// 内核虚拟地址
// ============================================================================

pub const KERNEL_VIRT_BASE: u64 = 0xFFFF8000000000000;
pub const KERNEL_PHYS_BASE: u64 = 0x100000;

// ============================================================================
// vmalloc 区域
// ============================================================================

pub const VMALLOC_START: u64 = 0xFFFFC900000000000;
pub const VMALLOC_END: u64 = 0xFFFFF000FFFF0000;

// ============================================================================
// 用户空间
// ============================================================================

pub const USER_END: u64 = 0x00007FFFFFFFFFFF;
pub const USER_MMAP_BASE: u64 = 0x0000400000000000;

// ============================================================================
// 页大小
// ============================================================================

pub const PAGE_SIZE: u64 = 4096;
pub const PAGE_SHIFT: u64 = 12;
pub const PAGE_MASK: u64 = !(PAGE_SIZE - 1);

pub const HUGE_PAGE_SIZE: u64 = 2 * 1024 * 1024;  // 2MB
pub const GIGANT_PAGE_SIZE: u64 = 1024 * 1024 * 1024; // 1GB

pub const HUGE_PAGE_SHIFT: u64 = 21;
pub const GIGANT_PAGE_SHIFT: u64 = 30;

// ============================================================================
// 其他
// ============================================================================

pub const STACK_SIZE: usize = 32 * 1024;  // 32 KB
pub const IST_STACK_SIZE: usize = 16 * 1024;  // 16 KB
```

## 内存映射

### 内核映射

```
物理地址           虚拟地址
0x100000    -->    0xFFFF_8000_0010_0000  (内核高半映射)
0x100000    -->    0xFFFF_8800_0001_0000  (直接映射)
```

### vmalloc 映射

```
虚拟地址                     物理地址（可能不连续）
0xFFFF_C900_0000_0000    -->    0x1000_0000
0xFFFF_C900_0000_1000    -->    0x2000_0000
0xFFFF_C900_0000_2000    -->    0x3000_0000
...
```

## 地址宏

```rust
#[macro_export]
macro_rules! phys_to_virt {
    ($phys:expr) => {
        VirtAddr::new($phys + DIRECT_MAP_OFFSET)
    };
}

#[macro_export]
macro_rules! virt_to_phys {
    ($virt:expr) => {
        const _addr: u64 = $virt.as_u64() - DIRECT_MAP_OFFSET;
        PhysAddr::new(_addr)
    };
}
```
