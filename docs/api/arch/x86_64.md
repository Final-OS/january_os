# x86_64 - x86_64 架构支持

x86_64 架构特定代码，包括串口和架构初始化。

## 文件

- `kernel/src/arch/x86_64/mod.rs` - 架构模块
- `kernel/src/arch/x86_64/boot.rs` - 运行时启动栈切换
- `kernel/src/arch/x86_64/io.rs` - 端口 I/O 抽象 (`inb/outb/inw/outw/inl/outl`)
- `kernel/src/arch/x86_64/serial.rs` - 16550 UART 驱动
- `kernel/arch/x86_64/linker.ld` - 内核链接脚本
- `kernel/src/virt/platform/x86_64/` - `virt` 子系统的 x86_64 平台后端（探测、VMX/SVM/EPT/irqchip/hypercall 占位）

## 启动栈切换

```rust
pub unsafe fn switch_to_runtime_boot_stack(
    entry: extern "C" fn(*const u8, usize) -> !,
    init_cmd: &str,
) -> !
```

用途：
- 在 `init::init_kernel()` 完成后切换到内核自有的运行时启动栈。
- 将 `init_cmd` 以 SysV ABI 约定放入 `rdi/rsi`，再跳转到通用 `runtime_entry`。
- 把 `x86_64` 专属寄存器与 `asm!` 细节从 `kernel/src/main.rs` 挪到架构层。

约束：
- 当前实现分配 64 KiB、4 KiB 对齐的临时启动栈。
- 跳转前会清空 `rbp`，并把栈顶额外对齐到 16 字节。
- 函数为 `noreturn`；成功后不会返回调用者。

## 链接脚本导出符号

`kernel/arch/x86_64/linker.ld` 会导出以下常用边界符号：

- `__kernel_start` / `__kernel_end`
- `__kernel_file_end` / `__kernel_file_size`
- `__kernel_mem_end` / `__kernel_mem_size`
- `__text_start` / `__text_end`
- `__rodata_start` / `__rodata_end`
- `__got_start` / `__got_end`
- `__data_start` / `__data_end`
- `__bss_start` / `__bss_end`

说明：
- `__kernel_file_size` 对应 `kernel.bin` 的文件镜像大小。
- `__kernel_mem_size` 包含 `NOLOAD` 的 `.bss`，反映运行时内存占用范围。

## 串口驱动

### 初始化

```rust
pub fn serial_init()
```

**步骤**:
1. 检测端口
2. 配置波特率 (38400)
3. 配置线路控制 (8N1)
4. 启用 FIFO

### 输出

```rust
pub struct SerialWriter;

impl fmt::Write for SerialWriter {
    fn write_str(&mut self, s: &str) -> fmt::Result {
        for byte in s.bytes() {
            // 写入串口
            unsafe { outb(0x3F8, byte); }
            // 等待发送完成
            unsafe {
                let _ = unsafe { inb(0x3FD) };
            }
        }
        Ok(())
    }
}
```

### 输入中断

```rust
pub fn serial_enable_rx_interrupt()
```

### 非阻塞读取

```rust
pub fn serial_try_read() -> Option<u8>
```

**环形缓冲区**:
```rust
static SERIAL_INPUT_BUFFER: Mutex<CircularBuffer<u8, 256>> =
    Mutex::new(CircularBuffer::new());

// 中断处理程序添加
SERIAL_INPUT_BUFFER.lock().push(c);

// 读取
if let Some(c) = SERIAL_INPUT_BUFFER.lock().pop() {
    return Some(c);
}
```

## 寄存器

### 16550 UART 寄存器

| 偏移 | DLAB=0 | DLAB=1 | 说明 |
|------|---------|---------|------|
| +0 | THR | DLL | 发送/接收 |
| +1 | IER | DLH | 中断使能 |
| +2 | FCR | IIR | FIFO 控制/中断 ID |
| +3 | LCR | - | 线路控制 |
| +4 | MCR | - | 调制解调器控制 |
| +5 | LSR | - | 线路状态 |
| +6 | MSR | - | 调制解调器状态 |
| +7 | SCR | - | 暂存寄存器 |

### 端口地址

| 端口 | 基地址 | IRQ |
|------|--------|-----|
| COM1 | 0x3F8 | 4 |
| COM2 | 0x2F8 | 3 |
| COM3 | 0x3E8 | 4 |
| COM4 | 0x2E8 | 3 |

## 使用示例

### 串口输出

```rust
use kernel::arch::x86_64::serial_init;
use kernel::drivers::tty::SerialWriter;

// 初始化串口
serial_init();

// 输出
write!(SerialWriter, "Hello, x86_64!\n").ok();
```

### 中断输入

```rust
use kernel::drivers::tty::{serial_enable_rx_interrupt, serial_try_read};

// 启用接收中断
serial_enable_rx_interrupt();

// 在主循环中读取
loop {
    if let Some(c) = serial_try_read() {
        kprint!("{}", c as char);
    }
    halt_with_interrupts();
}
```

### 串口配置

```rust
// 设置波特率为 115200
unsafe {
    outb(0x3FB, 0x80);  // 设置 DLAB
    outb(0x3F8, 0x01);   // DLL
    outb(0x3F9, 0x00);   // DLH
    outb(0x3FB, 0x03);   // 8N1
}
```

## 分页模式协商（LA57）

- 引导阶段支持 4-level 与 5-level 页表构建。
- 协商条件：
  - `kernel.layout.va_mode=la57_prefer`
  - `CPUID.(7,0).ECX[16] == 1`（CPU 支持 LA57）
  - `CR4.LA57 == 1`（固件已启用 LA57）或 boot trampoline 可成功完成 4->5 切换
- 若未满足条件，按 `kernel.layout.la57_fallback=4level` 回退 4-level 启动。
- `BootInfo v4` 同时传递：
  - `root_table_phys_addr`（实际 CR3 根）
  - `pml4_phys_addr`（兼容字段）
  - `kernel_layout.{va_bits,page_levels}`（运行时布局）
