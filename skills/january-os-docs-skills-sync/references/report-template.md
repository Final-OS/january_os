# Sync Report Template

Use this structure in the final response after changes:

## 1. Changed Files

- list all changed files grouped by subsystem

## 2. Docs Updates

- file path -> what was updated -> why

## 3. Skills Updates

- file path -> what was updated -> why

## 4. Verification

- executed commands and result

## 5. Remaining Gaps

- unresolved docs/skills follow-ups if any
